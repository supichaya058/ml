แสดงความสัมพันธ์ระหว่าง Keywords โดยดอกไม้แต่ละดอกแทน Keyword และเส้นทึบที่เชื่อมระหว่างดอกไม้แสดงว่า Keywords สองคำปรากฏร่วมกันในบทความเดียวกัน แนวคิดนี้เรียกว่า Keyword Co-occurrence หาก Keywords สองคำมีการปรากฏร่วมกันหลายครั้ง จะเห็นความสัมพันธ์ระหว่างคำเหล่านั้นชัดเจนขึ้น ส่วนเส้นประใช้แสดง Keyword Community Connection สำหรับคำที่อยู่ในกลุ่มแนวคิดเดียวกันแต่ในข้อมูล ที่แสดงในส่วนนี้ยังไม่มีค่า Co-occurrence โดยตรง โดยเฉพาะ Transformer ซึ่งเชื่อมโยงกับคำในกลุ่ม Vision & Language เพื่อให้เห็นตำแหน่งของคำดังกล่าวในเครือข่าย โดยไม่สร้างตัวเลข Co-occurrence ขึ้นมาเอง

ส่วนนี้แสดงแนวคิดของการสร้าง Feature Vector จากข้อความของบทความ โดยไม่ได้ใช้ Title เพียงอย่างเดียว แต่รวมข้อความสำคัญ 4 ส่วนเข้าด้วยกัน ได้แก่ Title + Abstract + Author Keywords + Index Keywords แล้วเก็บข้อความที่รวมกันไว้ในคอลัมน์ embedding_text ซึ่งมีทั้งหมด 5,427 ข้อความ จากนั้นนำข้อความเหล่านี้เข้าสู่ SPECTER2 เพื่อแปลงข้อความของบทความแต่ละรายการ ให้เป็นตัวเลขหรือ Vector จำนวน 768 ค่า ต่อบทความ จึงได้ Feature Matrix ขนาด 5,427 × 768 โดยแต่ละแถวแทนบทความ 1 บทความ และแต่ละคอลัมน์แทน Feature ของ Embedding ข้อมูล Embedding ที่ได้ตรวจสอบแล้วพบว่า ไม่มีค่า NaN และไม่มีค่า Infinity จึงสามารถนำไปใช้ในการเปรียบเทียบความคล้ายคลึง การจัดกลุ่ม การลดมิติ และการสร้าง Visualization ต่อไปได้

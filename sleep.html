ภาพรวมของกระบวนการ เริ่มต้นจากการรวบรวมข้อมูลบทความวิชาการด้าน Computer Science จำนวน 6,000 บทความ จาก 10 Subject Groups
จากนั้นใช้ Python และ Pandas สำหรับอ่านไฟล์ CSV รวมข้อมูลจากแต่ละ Subject และเตรียมข้อมูลสำหรับการวิเคราะห์
ขั้นตอน Data Cleaning ตรวจสอบ EID เพื่อหาบทความที่ซ้ำกัน และตรวจสอบกรณีที่ EID เดียวกันอยู่ในหลาย Subject พบว่า 276 EID อยู่มากกว่า 1 Subject จึงนำบทความกลุ่มดังกล่าวออก ทำให้ Dataset ลดจาก 6,000 → 5,427 บทความ
หลังจากนั้นมีการจัดการ Missing Value ทำความสะอาด Title, Abstract และ Keywords รวมถึงตัดข้อความ Copyright ที่ติดมากับ Abstract
จากนั้นทำ Keyword Normalization เช่น technologies → technology เพื่อให้คำที่อยู่ในรูปแบบต่างกัน สามารถนับรวมกันได้อย่างถูกต้อง

SPECTER2 คืออะไร? SPECTER2 ถูกใช้ในขั้นตอน Text Embedding เพื่อเปลี่ยนข้อความของบทความ ให้เป็น Vector ที่สามารถนำไปคำนวณต่อได้
ข้อความที่นำเข้าสู่โมเดลไม่ได้ใช้เฉพาะ Title แต่รวมข้อมูลสำคัญ 4 ส่วน ได้แก่ Title + Abstract + Author Keywords + Index Keywords แล้วรวมเป็นข้อความเดียวในคอลัมน์ embedding_text
หลังจากนั้น SPECTER2 จะสร้าง Vector จำนวน 768 ค่า สำหรับบทความแต่ละรายการ
ดังนั้นบทความจำนวน 5,427 บทความ จะได้ Embedding จำนวน 5,427 Vectors และรวมกันเป็น Feature Matrix ขนาด 5,427 × 768
แต่ละแถวของ Matrix แทนบทความหนึ่งบทความ ส่วนแต่ละคอลัมน์ แทน Feature หนึ่งมิติของ Embedding
Representation เหล่านี้สามารถนำไปใช้สำหรับ เปรียบเทียบความคล้ายคลึง, จัดกลุ่มบทความ, ลดมิติข้อมูล, วิเคราะห์ความสัมพันธ์ และสร้าง Visualization ได้
ขั้นตอนนี้เป็นการ นำโมเดล SPECTER2 ที่มีอยู่แล้วมาใช้สร้าง Embedding ไม่ได้หมายถึงการ Train SPECTER2 ใหม่

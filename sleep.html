💡 คำอธิบายโดยละเอียด

Text Embedding ใช้ SPECTER2 เพื่อแปลงข้อความของบทความเป็น Feature Vector จำนวน 768 dimensions

Text ที่นำเข้าสู่ Embedding ประกอบด้วย Title + Abstract + Author Keywords + Index Keywords และจัดเก็บในคอลัมน์ embedding_text

ผลลัพธ์มีขนาด 5,427 × 768 โดยหนึ่งแถวแทนหนึ่งบทความ และแต่ละคอลัมน์แทน Feature dimension

Embedding ไม่มี NaN และไม่มี Infinity จึงสามารถนำ Feature Matrix ไปใช้ต่อกับ similarity analysis, clustering, PCA, t-SNE หรือ UMAP ได้

ตำแหน่งของดอกไม้ใน visualization นี้เป็น exploratory visual grouping ไม่ใช่ค่าพิกัดจริงของ Embedding
